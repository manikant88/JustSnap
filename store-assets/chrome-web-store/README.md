# Docksnip Chrome Web Store assets

## Recommended listing order

1. `01-save-inspiration.png` — Save an image while browsing.
2. `02-organize-folders.png` — Group related visual references.
3. `03-snip-any-area.png` — Capture a precise part of a page.
4. `04-keep-references-close.png` — Keep the dock available while working.

## Export dimensions

| Asset | Dimensions |
| --- | ---: |
| Listing screenshots | 1280 × 800 px |
| Store icon | 128 × 128 px |
| Small promotional tile | 440 × 280 px |
| Marquee promotional image | 1400 × 560 px |

## Chrome Web Store presentation notes

- Use at least one and up to five screenshots.
- Keep screenshots full bleed with square outer corners and minimal text.
- Screenshots should show current, accurate product behavior.
- Promotional art should remain legible when reduced and should not resemble a plain screenshot.
- Avoid unverified rankings, badges, awards, and performance claims.

## Source treatment

The listing screenshots were created from the supplied Docksnip captures. Personal browser chrome and distracting page details were reduced so the extension remains the focal point. The promotional images use the current Docksnip logomark and dock visual language.
